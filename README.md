# 砸瓶解压 Bottle Smash

一个本地运行的手势解压网页游戏。用户用摄像头追踪手势，握拳抓住玻璃瓶并甩手投掷；也可以用鼠标或触控按住瓶子拖拽后松手。页面不做真实文字识别，不上传摄像头视频，也不保存用户内容。

## 使用

```bash
npm install
npm run dev -- --port 5194
```

打开：

```text
http://127.0.0.1:5194/
```

## 交互

- 摄像头模式：握拳靠近玻璃瓶，抓住后向外快速甩手投掷。
- 回退模式：鼠标或触控按住瓶子拖拽，松手投掷。
- 墙面目标：提前贴便利贴，写下想砸掉的事物；也可以上传照片作为墙面目标。
- 目标位置：便利贴和照片可拖到墙面上的不同位置，命中后会撕裂、震落并消失。
- 换一瓶：重新生成玻璃瓶。
- 音效：可开关，本地生成，不加载外部音频。

## 隐私

- 手部追踪模型和 WebAssembly 文件放在本地静态目录。
- 摄像头视频只在浏览器本机用于手势追踪。
- 上传照片只在当前浏览器页面中预览，不上传服务器。
- 不接入云端识别，不保存历史内容。
